# **App Name**: K-워케이션 콘텐츠 스튜디오

## Core Features:

- 원클릭 워케이션 패키지 생성: 지역 가이드, 숙박 시설 소개, 여행 코스, 뉴스레터 등 워케이션에 필요한 전체 콘텐츠 세트를 버튼 한 번으로 생성합니다.
- 대량 콘텐츠 팩토리: 특정 광역 자치 단체 내의 여러 하위 지역 콘텐츠를 구조화된 데이터를 기반으로 한 번에 수백 개씩 대량 생산합니다.
- 멀티 에이전트 편집 도구: 기획자, 작가, SEO 전문가, 팩트체커 에이전트가 협력하여 텍스트의 품질을 검증하고 최적화하는 편집 도구 시스템입니다.
- 비주얼 에셋 디렉터: 생성된 텍스트 주제와 맥락에 어울리는 블로그 커버 및 SNS용 카드뉴스 이미지를 AI가 자동으로 디자인합니다.
- 산업 특화 구조화 템플릿: 호텔, 관광지, 정부 지원 정책 등 각 업종별로 전문적인 정보를 수집할 수 있는 전용 입력 인터페이스를 제공합니다.
- 워드프레스 자동화 파이프라인: API 연동을 통해 생성된 콘텐츠를 워드프레스 웹사이트에 직접 등록하고 카테고리 분류 및 예약 발행을 자동 처리합니다.
- 콘텐츠 라이프사이클 대시보드: 기획, 초안 생성, 검토, 발행에 이르는 모든 콘텐츠의 제작 현황과 프로젝트 상태를 통합 뷰에서 관리합니다.

## Style Guidelines:

- 주요 색상: 신뢰감과 생산성을 상징하는 딥 테크 인디고 (#284EBE).
- 배경 색상: 작업 집중도를 높여주는 깔끔하고 개방적인 소프트 클라우드 그레이 (#F4F6FA).
- 강조 색상: 활성화된 상태나 주요 행동 유도 버튼을 위한 브라이트 스카이 사이언 (#17B9CE).
- 헤드라인은 현대적인 느낌의 'Space Grotesk'를 사용하고, 본문은 가독성이 뛰어난 'Inter' 폰트를 적용합니다.
- 여행, 업무 기기, 자동화 로봇을 상징하는 선명하고 단순한 선 형태의 모노라인 벡터 아이콘을 사용합니다.
- 대량 생산 도구와 미리보기 패널을 효율적으로 배치한 모듈형 벤토 그리드 레이아웃을 구성합니다.
- 콘텐츠 대량 생성 시 처리 상태를 직관적으로 보여주는 부드러운 진행 펄스 효과와 타이핑 애니메이션을 적용합니다.
